# ⚔️ Alarm Dungeon (알람 던전)

**"아침을 깨우는 가장 강력한 모험"**

Alarm Dungeon은 매일 아침 단순한 알람을 끄는 행위를 '던전 탐험'과 '몬스터 사냥'이라는 게임 요소로 승화시킨 **Gamification 기상 앱**입니다. 지정된 시간에 알람이 울리면 잠금 화면을 뚫고 몬스터가 출현하며, 랜덤으로 출제되는 퀴즈 미션을 클리어해야만 알람을 끄고 경험치를 획득할 수 있습니다!

---

## 🎮 주요 기능 (Features)

1. **로그인 및 용사 정보** 
   - 나만의 용사 이름을 등록하고 레벨(LV)을 관리합니다.
2. **알람 던전 생성** 
   - 원하는 시간, 요일, 그리고 몬스터 난이도(쉬움/보통/어려움)를 설정하여 알람을 등록합니다.
3. **강제 기상 전투 (Background Wake Up)**
   - 앱이 종료된 상태라도, 스마트폰이 잠겨있더라도 알람 시간이 되면 강력한 몬스터가 화면 전체를 차지하며 등장합니다. (Android 14 백그라운드 구동 완벽 지원)
4. **미션 클리어 (Mission Execution)**
   - 몬스터를 물리치기 위해 수학 퀴즈, 상식 퀴즈 등 무작위 미션을 통과해야 합니다.
   - 실패 시 알람은 계속 울리며 잠을 완벽하게 깨워줍니다!
5. **몬스터 도감 (Monster Dictionary)**
   - 자신이 물리친 몬스터들을 수집하고 도감을 채우는 재미를 제공합니다.

---

## 🛠 기술 스택 (Tech Stack)

- **Frontend:** Flutter (Dart)
- **State Management:** Riverpod
- **Local Storage:** SharedPreferences
- **Background & Alarm:** flutter_alarm, android_intent_plus, permission_handler
- **OS Support:** Android 11 ~ 14+ (Samsung, LG, Pixel 등)

## ⚠️ 설치 및 테스트 시 주의사항 (필독!)

안드로이드 최신 버전(Android 14 이상)의 강력한 백그라운드 보안 정책으로 인해, 알람 앱이 화면을 강제로 켜기 위해서는 **반드시 필수 권한 2가지**가 필요합니다. 테스트를 위해 앱(APK)을 설치하신 후 다음 절차를 꼭 진행해 주세요!

### 🔑 필수 권한 설정 가이드
1. **앱 초기 실행 및 팝업 확인**
   - 앱 설치 후 최초 로그인 시, 홈 화면 상단에 **[⚠️ 알람 화면이 자동으로 켜지지 않나요?]** 라는 노란색 배너가 뜹니다.
2. **전체 화면 알림 권한 허용**
   - 배너를 터치하면 스마트폰 설정 창으로 한 번에 이동합니다.
   - 설정 목록에서 **"Alarm Dungeon"** 을 찾아 스위치를 **'켜짐(허용)'**으로 변경해 주세요. (가장 중요합니다!)
3. **다른 앱 위에 표시 권한 허용**
   - 앱 자체 권한 팝업으로 안내되는 **[다른 앱 위에 표시(Appear on top)]** 권한도 반드시 허용해 주셔야 화면이 정상적으로 켜집니다.

*※ 위 권한들이 허용되지 않으면 안드로이드 OS가 앱의 실행을 강제로 막아, 화면이 켜지지 않고 상단바에 작은 팝업으로만 알람이 울리게 됩니다.*
